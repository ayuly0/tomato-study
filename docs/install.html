Installation & Setup Guide

Automated one-click installers configure Python virtual environments, pull Qt dependencies, and pin desktop shortcuts automatically.

System Requirements

Component Minimum Requirement Recommended
Operating System Windows 10, Ubuntu 22.04+, macOS 12+ Windows 11 (64-bit), Arch / Ubuntu 24.04
Python Runtime Python 3.10 Python 3.11 or 3.12 (via Astral uv)
Graphics Hardware OpenGL 2.1 / DirectX 11 via Qt RHI Dedicated GPU or Intel Iris / AMD Radeon
Disk Space ~180 MB (including virtual environment) 250 MB

Platform Installers

Choose your platform for automated one-click setup.

Automated Shell Setup

Checks for Python 3.10+, installs Astral uv if needed, builds a dedicated virtual environment, pre-compiles shaders, and registers a standard freedesktop `.desktop` launcher in `~/.local/share/applications/`.

git clone https://github.com/ayuly/tomato-study.git && cd tomato-study && ./install.sh && ./run.sh

Automated Windows Setup

Run inside PowerShell or CMD (or simply double-click `install.bat`). Handles execution policy bypass, prepares virtual environment, installs dependencies, and creates a desktop shortcut.

git clone https://github.com/ayuly/tomato-study.git ; cd tomato-study ; .\install.bat ; .\run.bat

One-Command Direct Execution with uv

If you have Astral uv installed on your system, you can run directly without manual virtual environment creation:

uv run python src/main.py

Standard Python Venv

Standard Python packaging without automation scripts:

python3 -m venv .venv && source .venv/bin/activate && pip install -e . && python src/main.py

Updating the Application

Keep your installation up to date with upstream security and feature updates:

Pull Latest Changes

Fetch the latest stable commits from main:

git pull origin main

Synchronize Dependencies

Update lockfile packages using uv or pip:

uv sync --all-groups

Troubleshooting Common Issues

Known solutions for system-specific runtime conditions.

PermissionError when enabling Strict Focus
Modifying the operating system hosts file requires elevated administrative rights. On Windows, right-click your terminal or launcher and select Run as Administrator. On Linux or macOS, run the launch script with appropriate file permissions or run under sudo. Tomato Study catches this safely and emits an in-app alert without crashing.
qsb shader compiler not found
Tomato Study pre-compiles shader.frag.qsb and ships it inside the ui/ folder. If you modify shader.frag and the qsb tool is not found, the app safely falls back to using the existing pre-compiled binary shader without interruption.
Lo-Fi study radio shows STREAM CONNECTION ERROR
The study radio streams live from https://audio.late.sh/stream. If your internet connection drops or the upstream radio undergoes routine maintenance, the internal audio streamer will attempt automatic reconnection every 5 seconds. The rest of the timer and OpenGL shaders function completely offline.
Wayland fractional scaling / window positioning on Linux
If your Linux compositor (e.g., GNOME on Wayland or Hyprland) has display scaling issues, you can enforce XWayland compatibility by starting with: QT_QPA_PLATFORM=xcb ./run.sh.
