Feature Matrix

10 Core Features of Tomato Study

Derived directly from our presentation poster and architecture specification. Every capability serves one purpose: helping students achieve and maintain uninterrupted deep focus.

Feature 01 · Visual Craft

2.5D Split-Card Flip & Minimalist Digital Clock

Choose between authentic mechanical split-flap flip cards with 2.5D perspective animations, or a razor-sharp digital clock font. Smooth 60 FPS transitions run with near-zero GPU overhead via Qt Quick scene graphs.

Feature 02 · Methodology

Pre-Configured Study Presets

Instantly switch between evidence-backed presets: Classic Pomodoro (25/5/15), Extended 50/10 Focus, and Flowtime. Presets configure work intervals, break lengths, and long-break cycles in a single click.

Feature 03 · Deep Flow

Flowtime Open-Ended Mode

Rather than forcing an abrupt alarm when you are mid-thought, Flowtime counts up seamlessly. When you decide to pause, Tomato Study automatically calculates earned break duration proportional to your actual focus time.

Feature 04 · Ergonomics

Smart Compact Mode

When resized below user-configurable width and height thresholds (default: 400x250px), the application automatically collapses borders and secondary controls into a minimal floating badge.

Feature 05 · Audio Stream

Integrated late.sh Lo-Fi Study Radio

Connects to curated lo-fi study music via an internal proxy thread that strips ICY metadata and forwards raw audio locally. Features real-time track title display, volume slider, and one-touch mute toggle.

Feature 06 · Distraction-Free

Instant Zen Mode

Press Z or double-click anywhere on the window to hide all chrome, borders, buttons, and cursors. Only the glowing clock digits and interactive background remain, turning your second monitor into a calm study station.

Feature 07 · GPU Pipeline

Live OpenGL Fragment Shaders

Hardware-accelerated GLSL fragment shader compiled to Qt QSB binary packages. Renders celestial stars, drifting meteors, and particle mouse trails with damping controls adjustable in Settings.

Feature 08 · Customization

Customizable Intervals & Auto-Start

Full numerical control over work minutes, short breaks, long breaks, and cycle intervals. Optional auto-start toggles for both work and breaks so you never have to remember to manually restart the timer.

Feature 09 · Velocity

Fully Rebindable Hotkeys

Keyboard-first workflow for uninterrupted momentum. Space for play/pause, R for reset, S for settings, Z for Zen mode, P for stream, and M for mute. Every shortcut can be re-bound to any key.

Feature 10 · Multitasking

Always on Top Window Stays

Pins the focus timer comfortably above full-screen IDEs, PDF textbooks, terminal sessions, and video lectures, ensuring your countdown remains visible at a glance without switching windows.

Endpoint Security Suite

Built-In Anti-Bypass & Data Privacy

Because willpower alone is often not enough when studying late at night.

Strict Focus Anti-Bypass

Modifies system hosts file during active work to redirect Facebook, YouTube, TikTok, Reddit, and X to localhost. Close events are intercepted to reject premature window closing during work sessions.

Privacy Screen Lock

When entering break sessions, automatically calls native OS workstation lock commands (Windows LockWorkStation, Linux loginctl, macOS pmset) to encourage stepping away from the desk.

AES-256 Storage & TLS Pinning

Encrypts configuration at rest using AES-256-GCM via Python cryptography, with SHA-256 TLS certificate fingerprint verification on audio streams to prevent man-in-the-middle attacks.
