The Problem: Why We Built Tomato Study

As computer science students, we experienced the daily frustration of sitting down to study, only to find our attention derailed after ten minutes by phone alerts, notification overload, and endless open tabs.

The Modern Student Reality

  • Frequent digital distractions: messaging notifications, social media pings, and tab overload.
  • Loss of attention within the first 10 to 15 minutes of independent study blocks.
  • Upwards of twenty minutes wasted trying to regain deep flow after an interruption.

Our Engineering Response

  • Native desktop presence: sits cleanly above editors and slide decks without Electron RAM bloat.
  • Zero subscriptions, zero tracking, and offline-capable core timer and shaders.
  • Restorative breaks: automated privacy screen locking so students actually step away and rest their eyes.

Get Started in 3 Steps

Zero manual configuration required. Production installers handle Python, virtual environments, and shortcuts automatically.

01

Clone Repository

Grab the code from GitHub to your local machine using git clone.

git clone https://github.com/ayuly/tomato-study.git
02

Run Automated Installer

Execute the installer script for your OS. It sets up uv, dependencies, and desktop shortcuts.

./install.sh # Windows: install.bat
03

Launch & Focus

Launch via the generated desktop icon, launcher script, or Astral uv.

./run.sh # Windows: run.bat
