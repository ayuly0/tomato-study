Engineered for Concentration

Every feature is built to protect your attention span and reduce cognitive overhead.

Timer Architecture

Dual Modes: Pomodoro & Flowtime

Switch between traditional countdown Pomodoro cycles (25/5/15 min) and unconstrained Flowtime mode, which counts up as you work and calculates proportional restorative break times automatically.

Visual Craft

2.5D Flip Clock & Minimalist Digital

Enjoy mechanical split-card flip animations or switch to a sharp digital typography layout. Double-click the screen or press Z to enter Zen Mode, hiding all chrome for uninterrupted visual focus.

Background Audio

Integrated late.sh Lo-Fi Stream

Embedded TCP streaming proxy directly forwards curated lo-fi study audio from late.sh, parsing metadata in real time with integrated volume controls and one-touch muting.

Graphics Pipeline

Procedural OpenGL Fragment Shaders

Compiled directly to Qt binary shader packages (QSB). Features procedurally generated celestial starfields, drifting meteors, and particle mouse trails running smoothly on the GPU.

Digital Wellbeing & Security Suite

Robust system-level endpoint controls that prevent bypassing study rules when willpower runs low.

Strict Focus Anti-Bypass

Temporarily redirects distracting social domains (Facebook, YouTube, TikTok, Reddit, X) to localhost in the OS hosts file during work sessions. Intercepts window close events to prevent premature exits.

Privacy Screen Lock

Automatically invokes platform-native workstation lock mechanisms upon transitioning into break periods: LockWorkStation on Windows, loginctl/xdg-screensaver on Linux, and pmset on macOS.

AES-256 Storage & Integrity

Protects configuration files at rest with AES-256-GCM encryption derived from machine credentials. Audio streams enforce strict TLS 1.2+ validation with SHA-256 certificate pinning.

Keyboard Shortcuts

Designed for speed without touching your mouse. Fully rebindable in the Settings panel.

Key Action Description
Space Play / Pause Start or pause current session timer
R Reset Reset current cycle back to start interval
S Settings Open or close configuration drawer
Z Zen Mode Toggle borderless distraction-free view
P Stream Music Toggle late.sh background radio playback
M Mute Audio Quickly toggle audio mute without stopping stream

Installation & Setup

Single-command automated setup across all major desktop environments.

Clones repo, sets up virtualenv, installs dependencies, and creates desktop shortcut:

git clone https://github.com/ayuly/tomato-study.git && cd tomato-study && ./install.sh && ./run.sh

Run in PowerShell or CMD to configure environment and create desktop shortcut:

git clone https://github.com/ayuly/tomato-study.git ; cd tomato-study ; .\install.bat ; .\run.bat

Run directly with Astral uv in one command without manual venv creation:

uv run python src/main.py
