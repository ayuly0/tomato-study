Credits, Links & Legal Notices

Tomato Study stands on the shoulders of remarkable open-source projects, community audio streams, and scientific productivity research.

Open Source Technologies

Core libraries and utilities that make Tomato Study possible.

PySide6 & Qt Quick

Developed by The Qt Company. Official Python bindings for the Qt framework, providing our high-performance declarative QML rendering engine and hardware RHI OpenGL graphics.

Astral uv

Developed by Astral Software. An extremely fast Python package and virtual environment resolver written in Rust, powering our deterministic dependency resolution.

late.sh Study Radio

Created and hosted by the late.sh community. A free, high-quality, uninterrupted lo-fi study music stream that powers the background audio in Tomato Study.

pyca/cryptography

Maintained by the Python Cryptographic Authority. Provides our robust, audited AES-256-GCM authenticated cipher and PBKDF2HMAC key derivation engine.

QtAwesome & Font Awesome 6

Maintained by Spyder IDE and Fonticons, Inc. Provides clean vector font icons rendered directly inside the Qt Quick scene graph without external image dependencies.

pytest Test Framework

The industry-standard Python testing framework, used to automate all 36 unit tests validating timer drift, state transitions, security blocks, and offscreen QML rendering.
