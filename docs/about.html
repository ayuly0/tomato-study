About Tomato Study

Created as a capstone project for Introduction to the Major and Soft Skills (Semester 1, 2026–2027). Built through modern AI-assisted vibe coding, rigorous unit testing, and agile team collaboration.

1. The Origin Story

Tomato Study originated from our real daily struggles as university students. Sitting down to write code or study algorithms, we repeatedly found our concentration derailed after 10 to 15 minutes by notification fatigue, social media pings, and browser tab overload. Existing focus timer tools were either bloated Electron applications consuming hundreds of megabytes of RAM, locked behind paywalls, or visually jarring.

We set out to create a dedicated, beautiful, lightweight native desktop companion that treats attention with respect: zero advertisements, offline capabilities, calm aesthetics, and system-level endpoint controls that prevent bypassing study goals.

2. Engineering Workflow & AI Collaboration

How our 5-member team leveraged AI tools across every stage of the software lifecycle.

Rapid Prototyping

Used Claude for generative UI wireframing and QML component synthesis. Claude accelerated building the 2.5D split-card FlipDigit cards, keybind listeners, and reactive QML property bindings in hours rather than weeks.

Error Diagnostics

Systematic Diagnostics with Gemini

Employed Gemini for deep debugging and error root-causing: configuring Qt6 RHI OpenGL shader compilation flags, resolving PySide6 background audio threading reconnects, and architecting the AES-256 test matrix.

Git & Continuous Quality Assurance

Our engineering lifecycle followed disciplined agile principles: feature branching, peer pull-request reviews on GitHub, and automated unit test execution with PyTest before every major merge.

3. Production Technology Stack

Selected for native speed, low resource consumption, and cross-platform reliability.

PySide6 & Qt Quick

Official Python bindings for Qt 6. Declarative QML provides butter-smooth 60 FPS animations with negligible CPU usage compared to Electron.

GLSL Fragment Shaders

Hardware-accelerated OpenGL fragment shaders compiled to Qt binary packages (QSB), rendering stars and reactive mouse trails entirely on the GPU.

Astral uv & Packaging

Blazing-fast Python package resolver and virtual environment manager, powering our one-click cross-platform setup scripts.

late.sh Audio Stream

Local TCP proxy server stripping ICY metadata and forwarding live curated lo-fi study radio beats directly into QMediaPlayer.

Cryptography (AES-256)

Authenticated AES-256-GCM encryption with PBKDF2HMAC key derivation, protecting local settings and study history at rest.

QtAwesome (Font Awesome 6)

Direct vector font icon rendering inside QQuickView, replacing all emojis with clean, scalable, platform-native glyphs.

4. Testing Analysis, Limitations & Roadmap

Honest engineering evaluation based on classmate testing and code reviews.

Proven Feasibility

Quality Assurance & Feasibility

Validated by 36 automated unit tests across timer transitions, monotonic drift resilience, HostsBlocker injection/removal, AES-256 roundtrip/tamper checks, and offscreen QML compilation. Bandit SAST scans report 0 security vulnerabilities.

Current Limitations

Identified Limitations

The background audio currently streams from late.sh, requiring an internet connection for music playback. Individual local MP3 audio files cannot yet be queued. Testing was concentrated primarily on Linux and Windows.

Future Roadmap

Planned Improvement Proposals

Phase 1: Local Audio Engine

Support local audio files (.mp3, .flac) and ambient noise generators (rainfall, cafe white noise).

Phase 2: Expanded Packaging

Signed macOS DMG installer, Homebrew formula, and Linux Flatpak publishing.

Phase 3: Study Analytics

Local focus time analytics dashboard, habit streak charts, and calendar export.
